# Online Quiz App

A quiz application project for exploring question presentation, user answers, and quiz flow.

## Overview

This repository contains the source for an online quiz experience. Check the implementation for exact supported question formats, scoring logic, and storage behaviour.

## Getting started

```bash
git clone https://github.com/saikishore2410/Online-Quiz-App.git
cd Online-Quiz-App
```

Follow the language- or framework-specific run instructions in the repository. For Node.js projects, use `npm install` and the scripts defined in `package.json`.

## Validation checklist

- Verify answer handling and score calculations
- Test question navigation and empty input
- Handle refreshes and duplicate submissions
- Add unit tests for boundary cases

## Scope

Confirm whether authentication, persistence, randomization, and timers are implemented before relying on them.
